Dependency: Go, webview(**Wails**)

Background:

- There's a directory containing a lot of comics.
- All comics are zip files.
- Metadata of comics are in their zip comments.

Requirements:

- An interface showing comic covers and some info.
- Select & Sort comics by certain rules, can be handled by plugins.
- An embedded viewer enables users to read a comic.
- Editable layout for plugins.
- lazy cover loading. scroll view.
- good performance & low memory consumption.
- enables UTF-8
